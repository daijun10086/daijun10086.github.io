# About photos

Place three or four photographs in this directory, then add one entry per image
to the `aboutPhotos` list in `app/about/page.tsx`.

Example:

```ts
{ src: "/assets/about-images/photo-1.jpg", alt: "Dai-Jun outdoors" },
{ src: "/assets/about-images/photo-2.jpg", alt: "Dai-Jun at work", position: "center 35%" },
```

Use `.jpg`, `.jpeg`, `.png`, `.webp`, or `.avif` files. The optional `position`
value adjusts the crop without changing the rectangular gallery layout.
